# 🚀 Finastra — Banking Simulation System

🌐 **Live Website:** https://finastra-website.vercel.app

A full-stack banking and finance simulation platform built for inter-college competition. Finastra integrates trading, virtual banking, loan systems, and real-time event performance into a single strategic ecosystem.

---

## 📌 Overview

**FINAST₹A 2026** is the flagship inter-college commerce and finance fest of THK Jain College, Kolkata.
Finastra powers the entire event through a connected digital system that simulates real-world financial decision-making.

At the core lies **FINSTER BANK** — a virtual banking engine that transforms all events into a unified financial ecosystem.

---

## 🏦 FINSTER BANK (Core System)

FINSTER BANK connects all events into a live financial simulation.

### Key Mechanics:

* 💰 Virtual bank accounts for each college
* 📈 Performance-based earnings from events
* 🔁 Reinvestment into high-stakes events (Auction & Trading)
* 💳 Loan system with risk-based decision-making
* 🏆 Profitability-based leaderboard (Best CR Award)

* Teams & Participants
